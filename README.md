# Álgebra-Lineal
La compañía de seguros Sure Tomorrow quiere resolver varias tareas con la ayuda de machine learning y álgebra lineal.

- Tarea 1: Encontrar clientes que sean similares para ayudar con el marketing.
- Tarea 2: Predecir la probabilidad de que un nuevo cliente reciba una compensación del seguro. ¿Puede un modelo predictivo funcionar mejor que un modelo dummy?
- Tarea 3: Predecir el número de compensaciones de seguro que un nuevo cliente pueda recibir utilizando un modelo de regresión lineal.
- Tarea 4: Proteger los datos personales de los clientes sin afectar la calidad del modelo (enmascaramiento u ofuscación de datos).
